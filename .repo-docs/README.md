# Internal Repository Docs

This directory holds hidden, versionable maintainer notes for agents and developers working inside this repository. These are not user-facing docs, release notes, package docs, or H3 public documentation.

## Index

- `S3TRACE.md`: lightweight OpenMW-Lua trace line format for temporary runtime evidence.
- `event-contract-annotations.md`: local annotation convention for cross-context event contracts.
- `ui-content-contracts.md`: retained OpenMW UI content ownership and lifecycle guard notes.

## Scope

Use these notes for repo-local conventions that help code review, debugging, and static validation. Keep them concise and close to current practice.

Do not add golden logs, repro saves, standalone debug module docs, or version-stamping policy here. Those are intentionally out of scope for this docs set.
