The cookbook is intentionally small.

Each recipe should get you to a working mental shape quickly, then send you to the deeper page that explains ownership, lifecycle, and performance.


Start with [Put a Black Square on the Screen](@/cod3x/docs/cookbook/ui-black-square.md) if UI is the thing blocking you, [Publish a Small Interface](@/cod3x/docs/cookbook/interface-contract.md) for reusable contracts, or [Profile a Hot Path With Pr0f1l3r](@/cod3x/docs/cookbook/profile-a-hot-path.md) when performance is the problem.
