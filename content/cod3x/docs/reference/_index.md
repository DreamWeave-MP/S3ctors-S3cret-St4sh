Cod3x's LuaLS annotations remain the most exhaustive machine-readable reference in this repository. This section supplies the human maps that make those symbols discoverable.

The long-term goal is a complete human-facing OpenMW Lua reference that can stand beside or replace the upstream reference for day-to-day use while preserving links and attribution to OpenMW.

For now, begin with [Module Context Matrix](@/cod3x/docs/reference/module-contexts.md), [Built-In Interfaces](@/cod3x/docs/reference/interfaces.md), [Glossary](@/cod3x/docs/reference/glossary.md), and the [Historical Evidence Index](@/cod3x/docs/reference/history-index.md).
