Start with [Signal](@/h3lp_yours3lf/docs/api/modules/signal.md) or [normalizePath](@/h3lp_yours3lf/docs/api/modules/normalize-path.md) for plain Lua utilities. [Debounce](@/h3lp_yours3lf/docs/api/modules/debounce.md) and the [timing helpers](@/h3lp_yours3lf/docs/api/modules/timing.md) use OpenMW clocks. [Pool](@/h3lp_yours3lf/docs/api/modules/pool.md) is an advanced allocation tool; [S3lf](@/h3lp_yours3lf/docs/api/modules/s3lf.md) is an installed interface, not a plain module constructor.
