These pages are reference material rather than a tutorial. The reference covers the [PlaylistEnvironment](@/s3maphore/docs/api/playlist-environment.md), playlist contract, live state model, cell-presence synchronization, player interface, [playlist and track metadata](@/s3maphore/docs/api/metadata.md), [settings](@/s3maphore/docs/api/settings.md), [loading and persistence](@/s3maphore/docs/api/lifecycle.md), events, death-track control, and every built-in `PlaylistRules` function. Each entry leads with its name and signature, followed by behavior, parameters, return values, caveats, and an example.
