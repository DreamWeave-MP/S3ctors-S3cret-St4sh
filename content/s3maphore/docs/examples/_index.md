Examples are starting points, not substitutes for the API reference. Read the [PlaylistEnvironment](@/s3maphore/docs/api/playlist-environment.md) first for the bindings available to playlist files, then read the linked reference page when changing a field or composing rules.

- [Contextual Combat Playlist](@/s3maphore/docs/examples/combat-playlist.md) — target types and reusable combat lookup data.
- [Presence-Based Playlist](@/s3maphore/docs/examples/presence-based-playlist.md) — object records, types, and content files.
- [Compound Context Playlist](@/s3maphore/docs/examples/compound-context.md) — combine several state and rule predicates.
- [Fallback and Priority](@/s3maphore/docs/examples/fallback-and-priority.md) — priority ordering and fallback selection.
- [Interface Control](@/s3maphore/docs/examples/interface-control.md) — register, inspect, and observe playback externally.
- [Custom Death Track](@/s3maphore/docs/examples/custom-death-track.md) — select, test, persist, and reset death audio.
